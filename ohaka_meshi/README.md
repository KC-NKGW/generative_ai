# お墓飯

「自分が亡くなった時にお供えしてほしいレベルでおいしかったご飯」を記録しておくための、個人用の記録アプリです。ローカルのPCだけで動作し、外部への公開は行いません。

## 使い方

1. 初回のみ [python.org](https://www.python.org/) からPython 3.11以降をインストールしてください（インストーラーで「Add python.exe to PATH」に必ずチェック）。
2. `run.bat` をダブルクリックすると、初回は自動で仮想環境の作成と必要なライブラリのインストールを行い、以後は起動のみ行います。
3. ブラウザで `http://127.0.0.1:5000` が自動的に開きます（開かない場合は手動でアクセスしてください）。
4. ホーム画面（記録する）から料理名などを入力して記録、「一覧を見る」で今までの記録をギャラリー形式で見返せます。
5. 一覧画面から Excel（.xlsx）・PDF での書き出しができます。
6. 「おすすめ」機能を使う場合は、下記の「おすすめ機能の使い方」を参照してローカルLLM（Ollama）をセットアップしてください（任意機能です。セットアップしなくても他の機能は問題なく使えます）。

サーバーを止めるには、`run.bat` を起動しているコンソール画面で `Ctrl + C` を押してください。

## おすすめ機能の使い方

これまで記録した料理の傾向から、「次はこんな料理はどうですか」と具体的な料理名を提案してくれる機能です。**完全無料・データは一切外部に送信されません**（お使いのPC上で動くローカルLLM「Ollama」だけで処理します）。実在するお店を検索する機能ではないため、具体的な店名の提案はしません（あくまで一般的な傾向からの提案です）。提案はそれぞれ、料理をイメージしやすい絵文字つきのカードで表示されます（AIが選ぶ絵文字なので、多少ズレることがあります）。

1. [https://ollama.com](https://ollama.com) からOllama（Windows版）をダウンロードしてインストールしてください。インストール後、自動的にバックグラウンドで起動します。
2. コマンドプロンプトまたはPowerShellで次のコマンドを実行し、モデルをダウンロードしてください（初回のみ。数GBのダウンロードが発生します）。
   ```
   ollama pull qwen2.5:3b
   ```
   もう少し高品質な提案が欲しい場合は、`qwen2.5:7b`（容量・必要メモリは大きくなります）に変更することもできます。その場合は `recommend.py` 内の `OLLAMA_MODEL` の値を書き換えてください。
3. `run.bat` でアプリを起動し、ナビゲーションの「おすすめ」から「提案してもらう」ボタンを押してください。
4. Ollamaが起動していない・モデルが未取得の場合は、画面にセットアップ手順が案内されます。

## 仕組み

- 記録内容：料理名・外食/内食の区分・レストラン名/場所（外食時のみ）・参考URL・スクリーンショット・感想・食べた日
- 参考URLを貼り付けると、そのページの `og:title` / `og:image` などのOGPメタデータをサーバー経由で取得し、タイトルや画像の自動入力を試みます（食べログ・デリッシュキッチン等では概ね機能しますが、GoogleMapの共有リンクなどは取得できないことがあります。その場合は手動で入力してください）。外食の場合は店名欄に、内食の場合は料理名欄に自動で入るよう振り分けられ、場所が取得できた場合はそちらも自動入力されます。
- スクリーンショットはファイル選択のほか、フォーム上でのクリップボード貼り付け（Ctrl+V）にも対応しています。
- データはローカルのSQLiteファイル（`ohaka_meshi.db`）に保存されます。削除は取り消せる「論理削除」（一覧には出なくなりますが、データ自体は残ります）です。
- 一覧はカード形式のギャラリー表示。キーワード検索・外食/内食の絞り込み・並び替え（食べた日が新しい順/古い順・料理名順）ができます。
- 一覧画面からExcel（openpyxl）・PDF（reportlab、日本語対応）としての書き出しが可能です（検索・絞り込み・並び替えの条件はそのまま反映されます）。
- 「おすすめ」機能：これまでの記録を、お使いのPC上で動くローカルLLM「Ollama」に渡して次に試したい料理を提案してもらいます。外部通信は一切行われません（詳細は下記「おすすめ機能の使い方」を参照）。

## 技術構成

- Python / Flask（サーバーサイドレンダリング、ビルドツール不使用）
- SQLite（標準 `sqlite3` モジュール）
- OGPメタデータ取得：`requests` + `beautifulsoup4`
- 画像リサイズ：Pillow
- Excel出力：openpyxl／PDF出力：reportlab（日本語CIDフォント使用）
- おすすめ機能：`requests` でローカルのOllama API（`http://localhost:11434`）を呼び出し（既定モデル：`qwen2.5:3b`）、外部通信は一切行いません
- ライトモード・ダークモードの両方に対応
