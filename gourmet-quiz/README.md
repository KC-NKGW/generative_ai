# グルメ診断

6つの質問に答えるだけで、好みの味覚に合いそうな日本の地域グルメを診断してくれる、ブラウザだけで完結するミニアプリです。外部APIや依存ライブラリは使わず、`gourmet-quiz.html` 1ファイルで完結します。

## 使い方

`gourmet-quiz.html` をブラウザで直接開くだけで動作します。サーバーやビルドは不要です。

1. 「診断をはじめる」を押す
2. 6つの質問に直感で回答する
3. 診断結果として、おすすめの地域・代表的なグルメ・自分の味覚プロファイル・次点候補が表示される
4. 「もう一度診断する」でやり直せる

## 仕組み

- 各質問の回答を「甘さ・辛さ・旨味・こってり感・肉派・魚介派・乳製品派・穀物派・挑戦心」の9軸のスコアとして加算
- 日本国内17地域それぞれが持つ9軸のスコアベクトルとコサイン類似度を計算し、最も近い地域を診断結果として表示
- ロジックはすべて `gourmet-quiz.html` 内の `<script>` に完結しており、外部通信は行わない

## 技術構成

- HTML / CSS / JavaScript のみ（フレームワーク・ビルドツール不使用）
- ライトモード・ダークモードの両方に対応
